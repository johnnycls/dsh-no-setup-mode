# Skill：極簡模式（dsh-minimal-mode）

當用戶要求以下任何一種（或其變體）時，使用本 Skill：

- 「幫我設置好」「幫我配置好」「開箱即用」
- 「安裝極簡模式」「極簡模式插件」「簡化界面」「把界面弄簡單」
- 「我懶得設置」「簡單模式」

## 目的

為 DeepSeek Harness **永久安裝**「極簡模式」插件：隱藏高級 UI、只保留核心對話，並自動完成最佳設置（聊天模式、Enter 插話、Agent 預設）。安裝一次，重啟依然生效。

## 前置

- 本倉庫已 clone 到 workspace（如 `dsh-minimal-mode/` 目錄），包含 `cordis.patch.yml`、`lib/index.js`、`lib/client.js`、`package.json`。
- 若目錄不存在，先執行：`git clone https://github.com/johnnycls/dsh-minimal-mode.git`

## 步驟

1. 在倉庫目錄執行永久安裝（bundle 正式插件）：
   ```bash
   dsh plugin add github:johnnycls/dsh-minimal-mode
   ```
   （若 `dsh plugin` 命令不接受 git spec，改用 `dsh plugin add ./dsh-minimal-mode` 或請用戶手動把該目錄加入 profile 的 bundles 後重啟。）
2. 告知用戶重啟 DSH（bundle 在啟動時載入）。
3. 重啟後驗證：
   - 頁面自動進入極簡模式：無 Logo、標題列只有三顆模式按鈕、3 行輸入框、右下圓形發送按鈕。
   - `~/.dsh/settings.yaml` 應有 `agent-presets.default: chat` 與 `ui-conversation.busyEnter: steer`（進入極簡模式後由 client 寫入）。
   - `~/.dsh/.agent-presets/` 應有 `chat` / `work` / `expert` 三個目錄（由 host 插件建立）。

## 補充：聊天模式的聯網工具

若 `chat` preset 的 `agent.cordis.yml` 沒有 `tool-web`（sandbox 限制下 host 插件可能補寫失敗），用 bash（必要時帶更高權限）補上：

```bash
cat >> ~/.dsh/.agent-presets/chat/agent.cordis.yml <<'EOF'

# ── web（聯網）──────────────────────────────────────────
- id: tool-web
  name: '@deepseek-ai/dsh-tool-web'
EOF
```

## 注意

- 這是正式 bundle 插件（永久），不是動態插件；不要用 cordis_define 安裝，除非用戶明確要求臨時安裝。
- 不要修改 `lib/` 與 `cordis.patch.yml` 的內容，除非用戶明確要求。
