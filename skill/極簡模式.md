# Skill：極簡模式（dsh-minimal-mode）

當用戶要求以下任何一種（或其變體）時，使用本 Skill：

- 「幫我設置好」「幫我配置好」「開箱即用」
- 「安裝極簡模式」「極簡模式插件」「簡化界面」「把界面弄簡單」
- 「我懶得設置」「新手模式」「簡單模式」

## 目的

為 DeepSeek Harness 安裝「極簡模式」插件：隱藏高級 UI、只保留核心對話，並自動完成 API Key / 模型 / Agent 預設等設置。安裝後一打開 DSH 即自動進入極簡模式（Full Access 權限）。

## 前置

- 本倉庫已 clone 到 workspace（如 `dsh-minimal-mode/` 目錄），包含 `host.js` 與 `client.js`。
- 若目錄不存在，提示用戶先 `git clone https://github.com/johnnycls/dsh-minimal-mode.git`。

## 步驟

1. 讀取 `host.js` 的**完整內容**（用 bash `cat dsh-minimal-mode/host.js`，確保無行號干擾）。
2. 讀取 `client.js` 的**完整內容**（同樣用 `cat`）。
3. 呼叫 `cordis_define`：
   - `name`：「極簡模式」
   - `purpose`：簡短說明（如「安裝後開箱即用：自動進入極簡模式，隱藏複雜 UI，自動完成設置」）
   - `plugin`：`{ kind: 'new', idPrefix: 'mini' }`
   - `code.host`：第 1 步讀到的 host.js 全文
   - `code.client`：第 2 步讀到的 client.js 全文
4. 呼叫 `cordis_run`（mode: run）啟動。
5. 若返回 `awaiting-approval`：告知用戶在頁面上核准。
6. 啟動後告知用戶：極簡模式已生效（聊天模式自動選中、Full Access、餘額顯示）。

## 驗證

- 頁面應立即進入極簡模式：無 Logo、標題列只有三顆模式按鈕、輸入框 3 行、右下圓形發送按鈕、輸入框下方餘額行。
- 可檢查 `~/.dsh/settings.yaml` 應有 `agent-presets.default: chat` 與 `ui-conversation.busyEnter: steer`。

## 注意

- 插件是動態插件（session 內有效；DSH 重啟後需重新安裝）。
- 不要修改 host.js / client.js 的內容，除非用戶明確要求。
